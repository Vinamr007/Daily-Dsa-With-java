# Java Basic Interview Questions & Answers

## 1. What is Java?

Java is a high-level, object-oriented, and platform-independent programming language. It is mainly used to develop backend applications, web applications, desktop applications, and enterprise software.

---

## 2. What are the main features of Java?

The main features of Java are:

- Platform Independent
- Object-Oriented
- Simple
- Secure
- Robust
- Multithreaded
- Portable
- High Performance
- Distributed

---

## 3. Why is Java platform independent?

Java is platform independent because Java code is converted into bytecode, and this bytecode runs on the JVM.

The same bytecode can run on different operating systems if the required JVM is available.

```text
Java Source Code
       ↓
   Java Compiler
       ↓
    Bytecode
       ↓
       JVM
       ↓
Operating System
````

---

## 4. What is JVM?

JVM stands for Java Virtual Machine.

It is responsible for executing Java bytecode and provides the environment required to run Java programs.

---

## 5. What is JDK?

JDK stands for Java Development Kit.

It provides the tools required to develop and run Java applications.

JDK contains:

* JRE
* Development tools such as the Java compiler

---

## 6. What is JRE?

JRE stands for Java Runtime Environment.

It provides the environment required to run Java applications.

JRE contains:

* JVM
* Java class libraries
* Supporting files

---

## 7. What is the difference between JDK, JRE, and JVM?

| JDK                                   | JRE                        | JVM                            |
| ------------------------------------- | -------------------------- | ------------------------------ |
| Used to develop and run Java programs | Used to run Java programs  | Executes Java bytecode         |
| Contains JRE                          | Contains JVM               | Part of JRE                    |
| Contains development tools            | Contains runtime libraries | Provides execution environment |

---

## 8. What is bytecode?

Bytecode is the intermediate code generated by the Java compiler after compiling a Java program.

It is stored in a `.class` file and is executed by the JVM.

---

## 9. What is a class?

A class is a blueprint or template used to create objects.

Example:

```java
//class Student {
//    String name;
//    int age;
//}
```

Here, `Student` is a class.

---

## 10. What is an object?

An object is an instance of a class.

Example:

```java
//Student s = new Student();
```

Here, `s` is an object of the `Student` class.

---

## 11. What is OOP?

OOP stands for Object-Oriented Programming.

It is a programming approach where we organize a program using classes and objects.

The four main pillars of OOP are:

1. Encapsulation
2. Inheritance
3. Polymorphism
4. Abstraction

---

## 12. What is encapsulation?

Encapsulation means wrapping data and methods together inside a class and controlling access to the data.

It is commonly achieved using private variables and public getter and setter methods.

Example:

```java
//class Student {
//
//    private int age;
//
//    public void setAge(int age) {
//        this.age = age;
//    }
//
//    public int getAge() {
//        return age;
//    }
//}
```

---

## 13. What is inheritance?

Inheritance is a mechanism where one class acquires the properties and methods of another class.

We use the `extends` keyword.

Example:

```java
//class Animal {
//
//    void eat() {
//        System.out.println("Eating");
//    }
//}
//
//class Dog extends Animal {
//}
```

Here, `Dog` inherits from `Animal`.

---

## 14. What is polymorphism?

Polymorphism means one thing having multiple forms.

In Java, polymorphism is mainly achieved through:

* Method Overloading
* Method Overriding

---

Method overloading means having multiple methods with the same name but different parameters in the same class.

---

## 16. What is method overriding?

Method overriding occurs when a child class provides its own implementation of a method already defined in the parent class.

Example:

```java
//class Animal {
//
//    void sound() {
//        System.out.println("Animal sound");
//    }
//}
//
//class Dog extends Animal {
//
//    @Override
//    void sound() {
//        System.out.println("Dog barks");
//    }
//}
```

Method overriding is also called runtime polymorphism.

---

## 17. What is abstraction?

Abstraction means hiding implementation details and showing only the necessary information to the user.

In Java, abstraction can be achieved using:

* Abstract classes
* Interfaces

---

## 18. What is a constructor?

A constructor is a special member of a class that is automatically called when an object is created.

Important points:

* It has the same name as the class.
* It does not have a return type.
* It is used to initialize objects.

Example:

```java
//class Student {
//
//    Student() {
//        System.out.println("Constructor called");
//    }
//}
```

---

## 19. What is the difference between constructor and method?

| Constructor                      | Method                       |
| -------------------------------- | ---------------------------- |
| Used to initialize an object     | Used to perform an operation |
| Same name as class               | Can have any valid name      |
| Does not have a return type      | Can have a return type       |
| Called when an object is created | Called explicitly            |

---

## 20. What is the `static` keyword?

The `static` keyword means that a member belongs to the class rather than to an individual object.

A static variable is shared among all objects of the class.

Example:

```java
//class Student {
//
//    static String college = "JJMCOE";
//}
```

We can access it using:

```java
//Student.college;
```

---

## 21. What is the `this` keyword?

`this` refers to the current object.

It is commonly used when instance variables and local variables have the same name.

Example:

```java
//class Student {
//
//    int age;
//
//    Student(int age) {
//        this.age = age;
//    }
//}
```

Here, `this.age` refers to the instance variable.

---

## 22. What is the `super` keyword?

`super` refers to the immediate parent class.

It can be used to:

* Access parent class variables
* Call parent class methods
* Call parent class constructors

---

## 23. What is an interface?

An interface is used to define a contract that implementing classes must follow.

We use the `interface` keyword.

Example:

```java
//interface Animal {
//
//    void sound();
//}
```

A class can implement the interface:

```java
//class Dog implements Animal {
//
//    public void sound() {
//        System.out.println("Bark");
//    }
//}
```

---

An abstract class is a class declared using the `abstract` keyword.

It can contain:

## 25. What is the difference between abstract class and interface?

### Abstract Class

* Can contain abstract and concrete methods.
* Can have constructors.
* Can have instance variables.
* A class can extend only one class.

### Interface

* Used to define a contract.
* A class can implement multiple interfaces.
* Supports abstraction.
* A class uses the `implements` keyword to implement an interface.

---

## 26. What is garbage collection in Java?

Garbage collection is the automatic process of removing objects that are no longer reachable or usable by the program.

The JVM's Garbage Collector manages this process.

---

## 27. What is String in Java?

String is a class in Java used to represent a sequence of characters.

Example:

```java
String name = "Vinamr";
```

Strings are immutable, which means their value cannot be changed after the String object is created.

---

## 28. Why is String immutable in Java?

String is immutable, which means once a String object is created, its value cannot be changed.

String immutability provides benefits such as:

* Security
* String pool optimization
* Thread safety
* Efficient memory usage

---

## 29. What is the main method in Java?

The main method is:

```java
public static void main(String[] args);
```

It is the entry point of a Java application.

### Meaning of each keyword:

* `public` → accessible to the JVM
* `static` → can be called without creating an object
* `void` → does not return a value
* `main` → method name recognized by the JVM
* `String[] args` → stores command-line arguments

---

## 30. What is the difference between Java and C++?

Some major differences are:

* Java is platform independent because of JVM and bytecode.
* Java does not support multiple inheritance through classes.
* Java provides automatic garbage collection.
* Java programs are executed through the JVM.
* C++ generally compiles directly to platform-specific machine code.
